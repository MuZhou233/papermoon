# Frozen PaperMoon Notes

Only implemented Notes can enter this directory. Use the [Note archival command](../README.md#archive-and-freeze). It adds the archive date, updates the bilingual record and appends immutable hashes.

Sealed triplets cannot be edited, translated, renamed, moved or deleted. Do not repair their historical outbound links. Keep this instruction file and the manifest at the archive root; artifact triplets live under class directories. Archived records are historical references, never current authority.
