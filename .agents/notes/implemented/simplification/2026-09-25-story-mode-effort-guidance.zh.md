# Agent Note: 故事模式 effort 提示

Status: implemented

[English](2026-09-25-story-mode-effort-guidance.md) | 中文

## 问题

第零章此前要求将 effort 锁定为所选模型的最低档，需要根据不同模型的能力确定最低值，并在请求中强制执行。修订后的体验将 effort 选择交给用户，只提供提示。

## 决定

[第四节](../../../../docs/story-mode/00/04-first-message.zh.md#模型选择与-effort-提示)现改为维护 effort 建议。这替代了[故事模式决定](../architecture/2026-09-24-playbook-and-story-mode.zh.md)记录的 effort 约束，保留自由选择模型，以及不影响普通会话和全局默认值的要求。本 Note 维护取消锁定的理由，[分层决策](../architecture/2026-09-25-story-mode-layers.zh.md)记录运行时实现。

章节通过通用机制读取模型能力及生效选择，不再要求最低档位推断接口、锁定 effort 控件或覆盖请求参数。章节负责决定何时显示建议，轨迹展示请求的实际值。

## 考虑过的替代方案

保留锁定可以确保每次练习都使用最低支持档位，但也会保留本次需求修订移除的强制执行和最低档位选择工作。自动选用推荐值仍会改变用户选择。建议让用户自行决定，不把采纳建议作为发送或完成章节的条件。

## 影响

需求及验收场景覆盖提示的显示与隐藏、切换模型及 effort，以及未采纳建议时仍能成功完成练习。示例输入框仍锁定，两种对话仍共用系统提示词。
