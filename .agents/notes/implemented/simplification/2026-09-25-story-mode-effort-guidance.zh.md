# Agent Note: 故事模式思考强度选择

Status: implemented

[English](2026-09-25-story-mode-effort-guidance.md) | 中文

## 问题

此前的最低思考强度规则要求推断不同模型档位的顺序，并在请求中强制执行。模型提供的选项与行为各异，章节目标则是让用户探索自己创作的角色。

## 决定

[第一个角色教学](../../../../docs/story-mode/fogbound-earthshine/01/05-reasoning-effort-and-first-performance.zh.md)讲解思考强度，允许用户选择任意受支持档位。没有可调档位的模型同样可用。章节读取原生模型能力并校验选项，选择由当前演绎保存，全局默认值保持不变。[分层决策](../architecture/2026-09-25-story-mode-layers.zh.md)负责接入。

## 考虑过的替代方案

最低档位锁定需要额外的排序与执行约束，自动选择则会改变用户偏好。讲解可能的影响并允许选择受支持档位，让用户观察模型行为，同时保持完成条件与具体档位独立。

## 影响

测试覆盖支持与不可用选项，以及无可调档位的路径。首条持久完整正文回复与成功章节提交决定完成。当前需求维护完整双语讲解和准确界面文案，旧建议与章节专属测试由 Git 保留。
