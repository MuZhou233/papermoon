# Agent Note: 闭包函数与主持人工具持久化

Status: implemented

[English](2026-09-13-closure-functions.md) | 中文

## 问题

起始消息无法执行有状态的决策。编剧需要普通函数，转换为工具后仍保留原有参数和返回值。结果交付中断时，状态变化必须保留，不能重复执行，也不能依赖日志之外的闭包状态。

## 决定

登记的工厂接收受保护的候选状态，返回带有显式 JSDoc 的命名函数。TypeScript 解析声明，Ajv 校验 JSON Schema，编译器将源码、所选语言文案和工具元数据冻结到产物。工厂不能写入状态。每次调用新建 Worker 和 VM，核对冻结函数身份，直接返回函数的 JSON 值，不重新生成 JSDoc 声明。

演绎串行执行调用，通过一条 Session 配置事件记录成功结果和新状态。日志是权威来源，校验和链与已记录的调用身份将动作关联到前一项。交付等待 DSH 持久化确认。确认失败时阻止该实例继续执行，并记录交付失败标记。重新打开后，通过现有展示替换机制恢复已提交结果，同时保留旧回执供历史检查。仅靠调用 ID 无法去重，日志调用序号用于区分独立请求。

[编译服务](../../../../plugins/playbook-compiler/README.zh.md)还使用同一执行器提供临时模拟。主持人工具保留原有名称、参数和结果，不附加状态或提示词。独立的只读 UI 展示状态与动作。[演绎插件](../../../../plugins/performances/README.zh.md)负责持久化与工具作用域，核心存储不依赖函数语法。

DSH 共用 schema 在精确匹配一个分支的 oneOf 之外支持包含式 anyOf；两者都至少包含两个分支，允许注解，拒绝同层类型约束。语言渲染器把两者表达为联合类型，校验仍保留不同的接受规则。schema 形式的 additionalProperties 校验未声明的键，命名属性保持各自规则。schema 遍历检查嵌套声明和循环。纯字典渲染为具有明确值类型的字典，混合对象的限制由工具包契约说明。

已保留结果的修复引用失败回执和至少一个更早的保留事件。消息、调用、来源、轮次、步骤及其他身份不变，只改变结果内容和错误标记。消费者校验应用保留的依据，Session 校验引用和身份，不解释产品状态。原回执仍可供历史请求读取。选中历史在所选路径内校验修复，封存的世界线节点不接受后续修复。

回复可见性采用随 effect 生命周期清理的预设登记。Compact 模式为已登记预设保留含回复的步骤，思考和工具折叠行为不变。流式完成和恢复后的视图采用同一策略；普通预设保留默认行为，Normal 模式保持展开。

## 考虑过的替代方案

把所有联合类型转成 oneOf 会拒绝重叠成员。无约束 JSON 会丢失校验和类型信息；只在消费者校验，会让登记器无法描述实际 schema。展平字典会改变工具数据。已证明成功后仍保留错误标记，会误述结果；重新执行可能重复副作用，追加第二份结果可能重复同一调用，修改旧回执会破坏请求依据。新增恢复事件会重复替换和来源机制。全局回复偏好会影响其他 Session；关闭过程折叠还会暴露思考和工具细节；修改记录则会把展示策略混入模型历史。

描述对象和平台规定的 status/result 包装会改变普通函数语义。从说明文字推导约束会增加未声明的行为。长期保留闭包会留下日志中不存在的状态。分开保存状态与回执，可能交付尚未提交状态的结果。恢复时重放函数可能重复产生效果。编译器原有的纯文本产物不足以执行函数，因此本决定扩展 [CommonJS 设计](2026-09-13-commonjs-opening-compiler.zh.md)，冻结可执行源码，不改写已经接受的修订版本。

## 影响

原有 oneOf 和布尔形式的对象开放性行为不变。不支持的 schema 关键字和无效组合在登记时失败。恢复不能修改身份或把成功改为失败，不新增 Session 字段、版本、Loop 阶段或 SDK 线协议类型。schema 与类型渲染测试覆盖重叠和未匹配联合、畸形分支、嵌套字典、类似原型的键及生成类型，录制 Session 保留原生声明。恢复测试检查依据、身份和历史保留。组件测试覆盖预设选择、流式和恢复后的回复、普通视图，以及思考和工具折叠。

提交时编译和不可变附件继续遵守[冻结修订版本规则](2026-09-13-frozen-revisions-and-performances.zh.md)。工厂不能根据当前状态更换工具身份，跨调用保存的值必须写入 state。抛错丢弃候选状态，返回 JSON 中的业务标记不由平台解释。

主库测试覆盖编译、模拟、执行、保存失败、回执恢复与 Fork。真实 DSH 和浏览器检查覆盖原生声明、原始结果、完整请求与只读检查。这些检查确认工程就绪，Playbook 创作和交互质量仍需体验反馈。

同文件别名包含连续的 JSDoc 注释块。显式字符串键字典编译为带值类型 Schema 的 additionalProperties；未限定字段或值类型的 object 仍不支持。DSH 适配器使用同一字典 Schema 校验。演绎组合在紧凑显示中保留中间回复，调用函数不会隐藏此前叙述。思考和工具行继续使用折叠控件。

[世界线](2026-09-16-worldlines.zh.md)选择动作祖先路径，并要求在节点封存前恢复回执。封存后的节点不能补写修复，证据缺失时阻止继续。
