# Agent Note: Playbook 上下文中的故事引导

Status: implemented

[English](2026-09-29-story-mode-contextual-guidance.md) | 中文

## 问题

故事存档跨越编辑、编剧对话与演绎。章节列表替换左侧导航会隐藏这些活动之间的路径。较长教学需要工作区旁稳定的阅读位置，也需要在没有 Session 的编辑页展示。

## 决定

[共用需求](../../../../docs/story-mode/README.zh.md#共用交互)将完整讲解与示例放在右侧故事引导，左侧导航和中央工具保持通常职责。[存档决策](2026-09-28-storyline-playbook-saves.zh.md)负责进度，[创作决策](2026-09-29-plaintext-playbook-authoring.zh.md)负责权限，显隐仅改变展示。

登记的 DSH 右栏补丁为真实 Session 上下文增加并列的页面上下文，共用标签、停靠渲染、宽度及全屏布局。PaperMoon 将当前编辑器或所属编剧／演绎解析为 Playbook。被动注册保留工具选择与展开状态。新建存档后右栏收起，浮层指向原生展开按钮，由用户打开引导；主动继续已有存档时打开引导。未查看更新在展开处或标签上提醒，当前内容展示后清除。阅读与已查看偏好独立于进度，代次检查隔离切换存档后的迟到响应。

简短[定位提示](../../../../plugins/ui-guidance/README.zh.md)指向真实控件，完整教学始终留在引导。浮层支持关闭、键盘操作和重新显示。窄屏定位外部控件前收起全屏引导，保留返回入口与阅读位置。原生会话页负责对话、输入、模型控件及轨迹。

入口和引导采用 DSH 主题变量及共用控件，紧凑的顶部和底部为长篇教学保留滚动空间。示例复用 `PromptTrace` 的轨迹条目与原文详情，通过显示标签保留每节术语的渐进顺序。新能力在中央控件旁显示“新解锁”标签，并强调对应编辑区域；提示持续到对应结果保存或演绎启动，从现有存档状态派生。

五节按概念前提展开：输入与回复、消息与上下文、系统指令、内容安排与模型差异、思考与演绎。讲解独立发展概念与建议，示例和分析随后承接。同一守灯人素材逐步增加角色标签、系统指令和内容位置变体，开场先于系统正文解锁，与这一顺序对应。比较保持为可选实践。

文本依据规则将完整双语文案留在需求。模型格式方面的技术启发保留为 [Hugging Face 聊天模板指南](https://huggingface.co/docs/transformers/chat_templating)及 [Gemma 格式指南](https://ai.google.dev/gemma/docs/core/prompt-structure)。它们支持工程上区分角色语义与模型输入格式；教学逐步介绍概念，将非常规内容安排视为可以比较效果的创作选择。

## 考虑过的替代方案

替换左栏会隐藏普通导航，中央教学页需要离开操作区才能阅读。完整教学放入浮层会让长文依附移动控件，额外右侧列又会与现有工具争夺空间。共用引导面板与短浮层支持边阅读边操作。

新建后自动展开会直接占用编辑空间；指向展开按钮的浮层能说明入口，并让用户决定何时阅读。进度更新自动展开会打断创作并替换选中的工具，提醒能保留用户选择。虚假 Session 会为 Playbook 引导引入无关执行身份，面板保存进度则会产生另一份权威数据。页面上下文与展示偏好保留这些边界。

原三入口教学结构分散了前提概念，仅增加一段介绍仍会保留这一问题。五个概念小节使讲解与实践对应。讲解提前引用示例会依赖后文，从段落位置提取提示又会耦合教学改写与控件引导。独立提示文本及讲解后的示例明确各自职责。

将文案留给运行实现会重新开启产品措辞决策，并允许需求与界面偏离。讲解、示例、控件及状态继续以需求为依据。

## 影响

右栏的直接包契约和测试随登记补丁维护，模型准入属于会话控制器补丁。客户端运行测试的装配工具在解析依赖前识别组合包所属包，使实际宿主测试能够载入 webapp 自有组合包，其回归加入登记检查。主仓库 Notes 维护这些补丁决定。

右栏测试验证独立面板、被动注册、工具选择保留和布局行为。确定性章节浏览器验证新建浮层与手动展开、轨迹示例的键盘选择、能力标签及其结束条件、无会话编辑、跨页上下文、存档隔离、收起提醒、键盘关闭及全屏返回。产品文案与当前需求核对，隐藏或收起引导始终保留授权与完成条件。

宿主构建产物通过编剧 schema 读取编剧会话的归属，因此故事模式将 `@papermoon/writers` 声明为运行依赖。构建检查会将保留的外部导入与产物所属插件的清单核对。回归测试覆盖相邻模块源码被打包后引入的依赖，即使本地残留的工作区链接能让导入成功，该检查也能发现清单缺项。
