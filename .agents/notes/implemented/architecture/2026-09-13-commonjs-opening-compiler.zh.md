# Agent Note: CommonJS 编译与起始上下文冻结

Status: implemented

[English](2026-09-13-commonjs-opening-compiler.md) | 中文

## 问题

程序与多语言文案需要一条供人工编辑器和编剧工具共用的编译路径。起始上下文提供了较小的可执行语言范围，可以先验证编译、产物保存与运行时职责，再扩展游戏机制。模块系统会长期影响剧本写法，不应依赖仍属实验阶段的原生 ESM VM 接口。

## 决定

[编译器](../../../../plugins/story-compiler/README.zh.md)通过 vm.Script 求值受限的同步 CommonJS，只提供带明确 .js 扩展名的相对依赖和一个虚拟 API。Acorn 检查实际加载的源码，不转译。解析出的 ESM 结构在求值前被拒绝，诊断说明平台的模块要求。声明诊断标明不支持的成员，不使用校验器内部对象的名称。每次编译独占 Worker、Context 和模块缓存，分别设置执行时限、外层总时限、取消和并发限制。

编译使用一种精确语言解析起始文本。[闭包函数决定](2026-09-13-closure-functions.zh.md)将可执行源码与状态纳入产物；本记录保留 CommonJS、文本初始化和独立存储的决定。[运行时](../../../../plugins/story-compiler/src/runtime.ts)校验产物，返回独立起始上下文，不执行程序。名称仅用于管理，编译器不附加角色指导或消息前缀，也不检查文学要求及未使用文案的翻译完整性。

服务读取确定的仓库快照，通过独立 JSON 适配器保存成功产物，再返回身份。内容、有效配置和编译器身份共同确定保存键。同一个键不能被不同结果覆盖。源码编辑或删除后，已保存产物仍可使用。修订提交使用[不可变附件](2026-09-13-frozen-revisions-and-performances.zh.md)，独立存储用于草稿检查。

编辑器与工具的显式编译共用服务。编辑器初始化已保存产物来生成预览，输入变化后将旧结果标为过期。工具编译不改变读取权限，也不引入发布或审批条件。[人工编辑器决定](2026-09-12-manual-script-editor.zh.md)继续负责编辑与本地缓冲区设计。

## 考虑过的替代方案

原生 ESM 能提供标准模块语义，但会让剧本语言依赖实验中的 VM 模块接口。打包或转译会增加模块解析和位置映射行为，首版文本编译器无需承担这些工作。初始化时重新执行源码，会让已接受产物的预览和运行再次依赖编译器执行。结果仅留在内存中，无法在重启后恢复；写入修订版本正文，则会把不断变化的派生格式与不可变创作内容混在一起。

## 影响

剧本语言不提供异步执行或宿主 I/O。运行期函数及其产物格式由闭包函数决定维护。Worker 和 VM 用于限制资源消耗，不承诺完整隔离恶意代码。成功产物持续保留，直到明确清理；完整性哈希不是签名。构建后的 Worker 用普通 Node 验证，真实 Cordis 测试覆盖清理，确定性模型和浏览器测试覆盖回执与预览，不调用真实模型。工程就绪与创作体验反馈仍分别记录。
