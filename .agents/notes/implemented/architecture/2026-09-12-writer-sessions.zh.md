# Agent Note: 编剧会话与读取保护

Status: implemented

[English](2026-09-12-writer-sessions.md) | 中文

## 问题

编剧配置需要进入可恢复、可审查的对话。多个 Agent 和人工编辑可以共享剧本。按目录识别工作区、共享读取权限，都不能表达这种归属关系。

## 决定

[会话插件](../../../../plugins/writer-sessions/README.zh.md)维护剧本目标、准备状态和接纳时固定配置。已接纳输入保存完整编剧快照，预置消息保留真实角色和稳定身份。运行期读取记录通过对象内容与草稿序号共同校验，存储与逻辑核心不承担会话策略。

## 考虑过的替代方案

虚拟剧本目录会混淆资源身份与进程 cwd。拼接起始消息会丢失角色；每次请求读取最新配置会改变历史上下文。独占绑定会阻止人工与多会话编辑。持久保存读取权限，会让恢复后的 Agent 获得当前读取生命周期之外的内容修改权。

## 影响

剧本和编剧数据库格式不变，通用工作区与消息能力通过 DSH 补丁维护。恢复、Fork 和插件重挂载建立新的工具作用域，要求重新读取。配置快照增加日志大小，但编剧配置变更或删除后，仍可审查原请求。
