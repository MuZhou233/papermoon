# Agent Note: 不可变演绎世界线

Status: implemented

[English](2026-09-16-worldlines.md) | 中文

## 问题

演绎需要保留不同结果，也需要保留先前的执行。从原始日志读取最新动作会混用兄弟分支的状态，删除消息则会丢失请求证据。历史选择还需要与后续的提示词组装分开。

## 决定

[演绎插件](../../../../plugins/performances/README.zh.md#世界线)在一个 Session 中，将一次输入及完整执行封存为节点。根节点和子节点均不可变。独立的选择记录保存当前祖先路径、候选上次选中的后续位置及操作身份。有校验和与版本的事实使用 DSH 必读的历史选择事件，不另建历史数据库。

动作继承选中父节点的状态，模型最终回复失败也不会撤销已提交变化。工具回执在节点封存前恢复。保存结果不确定或回执缺失时停止推进。恢复只封存中断工作，不执行函数。这限定了[持久函数](2026-09-13-closure-functions.zh.md)的恢复时机，其动作和产物规则继续有效。

## 考虑过的替代方案

隐藏子 Session 会把一次可见演绎拆成多份独立维护的历史。改写 JSONL 会移除证据。只按消息建节点会把未完成的工具协议暴露为续写位置。独立的回溯按钮需要用户自行协调历史选择与重新发送，编辑已发送消息则直接表达这一意图。世界线详情若复用对话中的操作控件，浏览历史结果就会改变运行位置。因此，详情只保留一个明确的切换按钮，生成操作留在对话中。可变树数据库会增加另一份权威状态。完整轮次节点既允许不同结果，也保留原始执行坐标。

## 影响

对话和轨迹跟随选择，审计与用量仍按发生顺序统计。重 roll 和编辑已发送消息都创建兄弟节点，新输入从选中位置分支。编辑将替换输入与生成合为一次操作，保留输入框中尚未发送的内容。读取和查看不改变运行位置。没有世界线记录的既有演绎只读，不推测补树。剧本与产物格式保持不变。

世界线读取提供稳定、有序的节点，不依赖模型消息。切换后仍可从请求前缀重建原始输入。以后可以用这些节点组装上下文窗口和摘要，无需重新定义已发生的历史。工程检查覆盖状态、请求、恢复、作用域和浏览器交互，体验反馈单独判断。
