# Agent Note: 编剧配置与独立作用域的 Playbook 工具

Status: implemented

[English](2026-09-12-writer-definitions-and-tools.md) | 中文

## 问题

编剧提示词需要独立于 Playbook 和会话编辑。Playbook 操作也需要面向模型的参数声明和清楚的回执，同时避免将 Agent 策略放进稳定的内容核心。如果另外维护一份 UI 工具列表，展示能力就可能与注册工具不一致。

## 决定

[编剧管理](../../../../plugins/writers/README.zh.md) 负责独立存储的配置、原始系统文本和保留角色的起始消息。代码中的最简模板用于新建配置，启动时不创建编剧。新建和复制均需确认，所有已存编剧均可编辑、删除。

提示词页负责可配置的消息内容，工具页负责独立声明，本版保持只读。轨迹式预览使用纯上下文解析函数。提示词名称作为编辑标签，不进入解析后的消息。工具帮助通过显式调用返回，不追加到起始消息。

配置按已知序号整体替换。浏览器导航偏好与数据库保存结果分开处理。页面切换时保留未完成的编辑，离开前要求明确选择保存或放弃。它不创建会话，也不修改运行时提示词。

[Playbook 工具](../../../../plugins/playbook-tools/README.zh.md) 维护单一目录及逻辑核心的执行适配。程序和文案分别批量操作。调用方指定目标 Playbook 和独立 DSH scope，模型参数不能将工具转向另一 Playbook。管理插件提供配置和目录接口。工具执行、scope 清理和结果校验继续由 DSH 负责。

## 考虑过的替代方案

编辑 DSH 预设组合文件会暴露插件组装细节，难以聚焦编剧配置。将提示词存入 Playbook 修订版本会把独立偏好与内容历史关联起来。永久保留只读编剧会把新建默认值混入用户管理的列表。在对话框确认前创建记录，取消后就会留下多余配置。全局注册工具会让无关对话获得 Playbook 修改能力。单个编辑工具可以支持跨领域批量操作，但会合并程序与文案的参数集；每个动作分别注册工具则会继续扩大工具目录。

## 影响

编剧配置使用独立 SQLite 文件及格式，现有 Playbook 格式保持不变。管理页使用 DSH 侧栏底部、主页面和浮层扩展，无需补丁。主库客户端共用 factory 打包函数。[工具编写标准](../../../../docs/development.zh.md#工具编写)让工具文案围绕调用需求展开，避免把工程细节写成创作指导或检查流程。修订版本查询错误由工具层标明模型参数及传入值，仓库规则仍由核心维护。帮助不注入提示词。[编剧会话](2026-09-12-writer-sessions.zh.md)负责会话激活、运行时上下文记录及读取策略。
