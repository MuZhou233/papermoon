# Agent Note: 产品定位与 DSH 发行版关系

Status: implemented

[English](2026-09-12-product-positioning.md) | 中文

## 问题

产品介绍需要让读者了解 PaperMoon 面向的体验，以及它与 DSH 的关系。仓库组织和启动方式分别属于维护说明与当前实现。

## 决定

[产品介绍](../../../../README.zh.md)以 AI 互动叙事说明 PaperMoon 的用途，以 DSH 发行版说明上游关系。产品面向 LLM 驱动的文字冒险游戏与角色扮演。“前端”描述面向用户的用途，实现可以包含浏览器代码和服务端逻辑。

本记录的已实施状态表示产品定位已经确定。[启动器决策](2026-09-11-submodule-launch.zh.md)记录当前运行基础，[维护决策](../process/2026-09-11-independent-maintenance.zh.md)规定主库与补丁各自的交付标准。

## 考虑过的替代方案

以插件与工具仓库介绍 PaperMoon，只能说明工程组织，读者仍无法了解它面向的体验。

用原版 DSH Web 启动器定义产品，会让当前实现代替长期定位，也无法说明文字冒险游戏与角色扮演的用途。

## 影响

产品介绍先说明使用场景及 DSH 发行版关系。维护文档说明仓库组织，已交付功能按当前实现描述。
