# Agent Note: 工具参数 JSON 错误

Status: implemented

[English](2026-09-15-tool-argument-json-errors.md) | 中文

## 问题

把格式错误的模型参数当作字符串继续传递，会让参数类型错误掩盖 JSON 解析失败。模型难以区分非法 JSON 和被对象 schema 拒绝的合法 JSON 字符串。

## 决定

Agent Loop 对每份参数字符串只解析一次，并保留语法错误。注册表通过现有参数物化路径接收错误，记录普通工具错误，不执行工具。诊断明确指出 JSON 无效，并保留原生解析器的原因及其能够报告的位置。调用记录保留原始参数。合法 JSON 与空参数字符串沿用现有校验行为。

## 考虑过的替代方案

**把原始字符串交给参数校验。** 这会丢失语法错误，可能误导模型修改参数。

**自动修复格式错误的参数。** 这会执行推断出的输入，而非模型记录中的调用。

## 影响

模型收到的错误与历史展示一致，可以重新提交修正后的调用。工具 schema、帮助文本和 Session 事件类型均不改变。详细措辞与可提供的位置由原生解析器决定。单元测试覆盖非法和合法输入、阻止执行及后续模型请求；无需密钥的 Session 快照覆盖持久错误和修正后的调用。
