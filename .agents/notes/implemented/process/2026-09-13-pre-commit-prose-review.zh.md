# Agent Note: 提交前的文字审阅

Status: implemented

[English](2026-09-13-pre-commit-prose-review.md) | 中文

## 问题

双语文档即使通过配对和结构检查，仍可能语句生硬、主语不清。写作指南的链接能让 Agent 找到它，却没有规定应当在哪一步使用。

## 决定

[提交前流程](../../../../docs/testing.zh.md#提交前检查)要求 Agent 读取[写作指南](../../../skills/bilingual-syntax-style-guide/SKILL.md)，结合上下文审阅修改过的文字，再更新双语记录。交付和文档 skill 都指向这一步。交付时分别说明文字审阅和自动检查的结果。

指南保留用户提供的原文及现有文件格式，相关选择见[写作技能记录](2026-09-12-verbatim-writing-skill.zh.md)。

## 考虑过的替代方案

只保留通用写作提醒，仍没有明确的审阅时机。禁用词列表无法判断句子的主语是否正确，也无法确认技术含义是否保留。Git hook 不能证明这一步审阅确实做过。

## 影响

Agent 结合上下文审阅本次修改的文字，审阅范围不扩展到无关文档。没有文字变更时，跳过这一步。审阅沿用现有交付流程，不增加自动风格评分或用户审批步骤。
