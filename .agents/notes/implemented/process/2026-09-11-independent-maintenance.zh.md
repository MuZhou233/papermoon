# Agent Note: 独立主仓库维护

Status: implemented

[English](2026-09-11-independent-maintenance.md) | 中文

## 问题

PaperMoon 需要完整的维护工具和规则。主仓库中的产品迭代不应被要求遵循 DSH 内部交付制度。

## 决定

主仓库维护自己的工程规则、双语文档、改编后的检查器，以及 Agent Note 从创建到归档的完整流程。作用于 DSH 的补丁保留其代码和运行时约束；[补丁维护决定](../architecture/2026-09-18-patch-maintenance.zh.md)规定资料、决定记录和交付范围。检查通过明确的命令和 CI 执行，主仓库不另设 hook 安装器。

## 考虑过的替代方案

整体继承 DSH 规则，会让其内部制度约束无关的主仓库代码。调用子模块私有检查器，会让维护工具随运行时一起升级。推迟归档检查，则无法及时发现已封存记录被改动。

## 影响

主仓库独立维护一套较小的检查器及来源记录。机器检查哈希和结构，人工审阅文字质量，并确认整合后的 Note 保留了原有理由。归档检查同时保护已封存的内容和对应清单，防止两者被一起改写。
