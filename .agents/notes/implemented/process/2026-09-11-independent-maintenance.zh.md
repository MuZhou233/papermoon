# Agent Note: 独立主仓库维护

Status: implemented

[English](2026-09-11-independent-maintenance.md) | 中文

## 问题

PaperMoon 需要完整的维护基础设施，同时避免每次产品迭代都与 DSH 内部交付规则耦合。

## 决定

主仓库拥有工程规则、双语文档、改编检查器及完整 Agent Note 生命周期。作用于 DSH 的补丁遵循子模块规则，其决定不在父仓库重复记录。检查和 CI 显式运行，不设置自定义主库 hook 安装器。

## 考虑过的替代方案

整体继承会让框架内部制度约束无关主库代码。调用子模块私有检查器会使维护升级和运行时升级耦合。推迟归档检查会让已有决定缺少生命周期保护。

## 影响

父仓库独立维护较小的检查器代码及来源记录。哈希和结构由机器检查，编辑质量和完整整合仍需审查。冻结归档同时阻止改写既有内容及其清单。
