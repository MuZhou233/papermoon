# papermoon-docs

Read [documentation rules](../../../docs/AGENTS.md). Identify the owning document before editing. Update the English and Chinese sides together. Read the [bilingual writing guide](../bilingual-syntax-style-guide/SKILL.md), review each language for natural phrasing, then compare meaning, technical literals and localized links. After that review, run the explicit recording command and documentation checks from the [checker guide](../../../tooling/checks/README.md). Do not reinterpret hashes as translation-quality approval. Do not record archived pairs.

For DSH package contracts carried in patches, follow the [patch documentation scope](../../../patches/README.md) and the checkout's pair format. Keep their recording separate from main-repository checks; do not expand the task into full-site documentation synchronization.
