# 测试与交付

[English](testing.md) | 中文

## 主仓库

开发过程中运行相关行为测试，提交前执行受影响的检查命令。CI 运行完整主库检查。测试覆盖解析失败、生命周期转换、Git 基准、进程取消和真实补丁重建。主库检查不构建或检查 DSH 源码，不设置逐文件覆盖率指标。workspace 源码别名让插件测试和文档示例无需预先构建插件即可运行。

文档检查只读。即使实际仓库没有图表、类型摘录或归档，夹具仍验证合法与非法示例。自动检查验证文档结构、内容哈希和命令结果。翻译是否准确、替代方案的理由是否充分、整合后的 Note 是否保留全部重要论据，由审查者判断。

主库流程区分工程就绪和产品体验反馈。主库变更不强制提供真实模型轨迹或 GIF。

## 交付流程

提交变更或报告就绪前，使用[交付技能](../.agents/skills/papermoon-checks/SKILL.md)，按以下顺序交付主库变更和 PaperMoon 携带的 DSH 补丁。检查命令按下文对应的范围选择。

1. **功能实现。** 完成本次需求，更新受影响的测试和直接契约，准备文档和所属 Note。
2. **基础检查。** 按主库或 DSH 补丁的维护范围，选择并运行相关行为测试、静态检查或文档检查。确认检查覆盖本次行为变化。
3. **界面设计复审（涉及 UI 时）。** 本次变更影响用户可见的信息、布局、控件、反馈或交互时，按下文要求重新审视完整界面，在本次需求和受影响区域内落实收益明确的改进。
4. **最终验收。** 对照需求验证最终变更，确认实现、测试、文档和所属 Note 一致。主库变更完成[提交前检查](#提交前检查)，作用于 DSH 的变更完成[补丁检查](#dsh-补丁)。继续修改后，重建受影响产物，重跑受影响的检查；内容保持原样时，沿用已通过的结果。
5. **交付。** 说明已完成的功能、改动和验证。报告实际运行的检查，区分跳过的检查和已通过的结果，说明相关限制和仍待验证的部分。

内部和纯文档变更从基础检查直接进入最终验收。

### UI 变更

基础检查通过后，重新评估信息组织、视觉层级、控件组合和交互负担，判断是否存在收益明确的改进。设计与交互遵循 `dsh/.agents/skills/dsh-client-ui-ux/SKILL.md` 中的原则，维护和交付遵循 PaperMoon 的范围约定。

在本次需求和受影响区域内落实收益明确的改进。当前方案合适时，保留实现并说明具体依据。最终验收覆盖复审后的界面和关键交互，验证证据应对应最终变更。复用现有检查，按行为变化补充所需验证。交付报告说明复审结论、改进或保留设计的依据。[流程决定](../.agents/notes/implemented/process/2026-09-30-ui-design-review.zh.md)记录复审时机和职责划分的理由。

## 提交前检查

最终验收时，修改主仓库的 Agent 执行以下步骤；提交时再完成暂存差异检查。作用于 DSH 的变更采用下文的补丁交付范围。

1. 检查本次差异，包括新增文件。确认代码、文档和所属 Note 描述的行为一致。
2. 本次变更含有中文或英文文字时，读取[双语写作指南](../.agents/skills/bilingual-syntax-style-guide/SKILL.md)，结合上下文审阅修改过的段落。范围包括文档、Note、skill 指令、注释和面向用户的文字。先按各语言的习惯检查措辞是否自然。有双语配对的文档，再核对两种语言的含义与技术细节。标识符、协议值和要求保留原文的内容保持原样。没有文字变更时，无需语感审阅。
3. 修改并审阅文字后，更新受影响的双语记录，运行相关检查。已通过检查的内容没有变化时，沿用已有结果；继续修改后，重跑受影响的检查。
4. 提交时检查暂存差异，运行 `git diff --cached --check`。确认应提交的文件已纳入，私有数据和构建产物未混入。若文字在审阅后又有修改，提交前重新审阅改动部分。

语感审阅由执行任务的 Agent 负责。自动文档检查能核对结构、链接和哈希，不能代替句法与语感审阅。交付时分别说明文字审阅和命令检查的结果，只报告实际审阅过的内容。

## DSH 补丁

在补丁清单中登记覆盖 DSH 实际修改的包脚本和参数数组。保留行为测试与录制回放、类型检查、lint 和运行时生成目录检查。新增行为应覆盖受影响的消费者；展示、持久化或接口变化仍需相应的 DSH 验证。审查者判断覆盖范围，不能只看命令成功。[补丁指南](../patches/README.zh.md)规定文档和决定记录的维护范围，DSH 全站文档汇总检查不属于补丁交付范围。

源码比较与交付检查各有用途。机械重组应证明与原有源码等价，无需重复未改变行为的检查；行为变化需要相应测试。源码比较拒绝未登记在补丁中的差异。检查不得改写维护中的源码和预期结果。

## 隔离与 CI

测试使用临时 Git 仓库、文件和本机回环端口，无论成功还是失败都释放资源。进程测试根据实际就绪状态继续，不靠固定延时猜测启动是否结束。测试核对文件和进程的实际结果，不只看命令报告了什么。

主库 CI 无需获取子模块即可运行检查并构建主库插件，再通过 `pnpm check:plugins:pure` 验证构建后的核心导入。集成工作流在 Gitlink、补丁、启动器、构建、存储、核心、编辑器、编剧和工具插件、UI 组件、profile 及相关依赖变化时运行，完成子模块初始化、构建、补丁检查，使用真实 Cordis 执行 `pnpm check:plugins:dsh`，再执行原版 Web 启动验证和 `pnpm test:editor`。浏览器场景使用临时运行数据，验证人工编辑、历史、恢复、冲突和认证；CI 先安装 Chromium。存储和业务仓库单元测试使用临时数据库，不依赖 DSH；独立插件检查使用构建产物，不启动 Web 或调用模型。集成路径过滤范围之外的文档变更不会触发 DSH 构建。

CI 中的归档检查以可信的 PR 基准或推送前提交为准。本地默认对照 HEAD；确认仓库尚无提交后，才使用空基准。明确指定的基准无法读取时会报错。测试夹具使用自己的 Git 历史，不能改写仓库的归档基准。

编剧单元测试覆盖配置、原文上下文和未保存选择。Playbook 工具测试使用临时仓库，真实 DSH 检查另外验证 scope 隔离及工具输出校验。浏览器场景覆盖提示词排序、只读目录展示、导航保护和保存冲突。主库检查保持独立，不依赖受管子仓库。

编剧会话检查使用真实 DSH 接纳、请求组装和工具服务。`pnpm test:writer-sessions` 通过确定性适配器驱动临时 Web 会话，检查实际发送的消息、固定配置、恢复、起始上下文展示，以及切换模式时保留未发送文字，不连接模型服务商，也不复用用户运行数据。

编译器测试覆盖受限模块、消息原文、缺译、时限、取消、确定快照和不可变产物写入。主库 CI 另运行 `pnpm check:compiler:built`，无需 DSH。编译器目录纳入集成检查的路径筛选。真实工具与编剧运行时检查包含异步 `playbook_compile` 回执；浏览器场景覆盖保存确认、诊断跳转、来源变化和产物恢复。构建后检查报告本机 Node 版本，本机通过不代表 CI 已通过。

提交测试覆盖编译失败、多目标、最终序号冲突、取消、附件上限和原子回滚。存储测试主动损坏或删除正文，验证修订共享及最后引用回收。演绎测试先关闭编译器，再读取冻结产物。pnpm test:writer-sessions 还检查仅有开场的会话、首轮真实请求、Fork 和来源删除。通用 DSH 展示补丁另行验证列表、搜索、事件校验和 SDK。

闭包函数测试覆盖 JSDoc、工厂写入保护、原始返回值、候选回滚和临时模拟。动作测试检查去重、持久化确认失败、回执恢复与 Fork 后的独立状态。真实 DSH 集成在编译器关闭后执行冻结函数，浏览器测试检查原生工具、状态与动作历史。包含式联合的通用补丁另有 Schema、类型渲染和录制会话检查。

反馈回归测试覆盖同文件连续 typedef、字典值类型及类型注解定位。客户端展示测试覆盖预设登记与清理、中间回复可见、思考折叠及普通对话行为不变。浏览器场景使用确定性适配器，检查工具调用结束及刷新后的回复展示。

世界线检查覆盖不可变兄弟节点、路径状态、中断封存、回执缺失和操作去重。DSH 集成验证实际请求与持久格式往返；浏览器场景检查重 roll 用户气泡、编辑已发送输入、分支连线、查看而不切换、刷新及窄屏树导航。原始用量不随选择回退。检查使用临时数据和确定性适配器。

上下文检查使用固定目录和冻结产物，覆盖拼装、无效引用、只读状态、资源限制和取消。演绎集成逐份比对检查接口与确定性适配器实际收到的消息，覆盖历史窗口、多步工具续接、重 roll 和恢复。浏览器检查覆盖整轮查看、模式恢复、来源导航和窄屏。DSH 轨迹测试覆盖引用顺序、完整工具回执、只读数据源释放及共用详情渲染；主库测试拒绝过期的检查响应和混用的分页游标。默认请求路径、编剧及普通 DSH 对话继续接受回归检查。

故事模式检查覆盖 Playbook 存档隔离、分阶段人工／工具权限、启动恢复、原子章节提交和有界回顾。`pnpm test:story-mode` 使用真实 DSH 应用和确定性适配器，验证[第一章五节](story-mode/fogbound-earthshine/01/README.zh.md)、实际请求内容、后续草稿保留、刷新及上下文引导。编辑器与编剧会话浏览器套件验证共用控件。主库测试核对教学与当前需求，DSH 测试覆盖页面／会话右栏与局部模型选择。
