# 第零章第二节：查看对话示例

[English](02-conversation-example.md) | 中文

本需求属于 [hello world](README.zh.md)，遵循[共用交互要求](../README.zh.md)。

## 体验与界面

查看配置后，展示一段预置对话，包含用户消息 `hi` 和硬编码的模型回复。沿用 DSH 的视觉风格区分双方角色，明确标注这是示例，避免用户误以为回复来自自己配置的模型。

示例保留可见但锁定的输入框，不能输入、粘贴或编辑文本，发送也不可用。示例使用[本章系统提示词](README.zh.md#对话上下文)。

示例内容由故事模式包提供。展示示例不发送模型请求，也不验证凭据。示例与后续练习会话分开，不得进入练习会话的对话历史或请求上下文。

## 推进条件

示例旁提供“继续”。显示回复或等待不会推进步骤；用户点击后才完成本小节，进入[查看示例轨迹](03-example-trajectory.zh.md)。

## 验收场景

- 示例显示 `hi`、固定回复、清晰区分的发言角色及明确的示例标识。
- 可见的输入框始终锁定，发送控件和键盘快捷键均不能提交消息；示例请求完整采用本章系统提示词。
- 打开、刷新或恢复本步骤均不发送模型请求，也不向真实练习添加消息。
- 用户点击“继续”之前，进度一直停留在示例步骤。
