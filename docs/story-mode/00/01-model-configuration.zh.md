# 第零章第一节：检查模型配置

[English](01-model-configuration.md) | 中文

本需求属于 [hello world](README.zh.md)，遵循[共用交互要求](../README.zh.md)。

## 体验与界面

引导用户查看模型配置页，并提供直达按钮。允许使用任意提供方。已有配置的用户不必重新填写，但仍须在本次练习中打开配置页。关闭配置页后回到本步骤。

明确显示当前选中的模型，以及所需配置是否齐备。这次检查不锁定后续练习的模型选择。通过已有模型与凭据机制读取配置状态，不另建 API Key 表单，也不发送验证请求。配置齐备不代表真实请求必然成功，第四节会让用户实际体验模型回复。

## 推进条件

只有本次练习中实际打开过模型配置页，且所选模型的必要配置齐备，才解锁“继续”。仅点击直达按钮但未打开页面，不算完成查看。配置缺失或无法读取时，“继续”保持不可用，并显示阻止推进的原因。

两个条件均满足后不自动前进。用户点击“继续”，才将本步骤记为完成并进入[对话示例](02-conversation-example.zh.md)。保存的进度保留本次练习中已查看配置页的结果；重新开始后需要再次查看。

## 验收场景

- 已有模型配置也不能跳过查看要求；打开页面且配置齐备后即可继续，不要求重新输入凭据。
- 只查看页面但配置不完整时不能推进；补齐配置后解锁“继续”。
- DeepSeek 之外的提供方也能满足要求；凭据要求遵循提供方配置，不假定所有提供方都需要 API Key。
- 本步骤不发送模型请求，满足两个前置条件后仍须明确点击“继续”才推进。
