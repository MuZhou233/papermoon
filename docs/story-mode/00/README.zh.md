# 第零章：hello world

[English](README.md) | 中文

第零章确立进入故事模式、跟随章节进度和完成练习的交互方式，同时约束章节专用体验与 PaperMoon 通用机制的职责边界。

## 体验

遵循[共用交互与实现约束](../README.zh.md)。本章名为 `hello world`。用户先查看模型配置，再阅读预置的对话示例及其轨迹，随后在全新的练习对话中发送自己的消息，并查看这次真实对话的轨迹。

| 顺序 | 小节 | 推进方式 |
|---|---|---|
| 1 | [检查模型配置](01-model-configuration.zh.md) | 满足查看及配置要求后，点击“继续”。 |
| 2 | [查看对话示例](02-conversation-example.zh.md) | 查看静态示例后，点击“继续”。 |
| 3 | [查看示例轨迹](03-example-trajectory.zh.md) | 打开示例轨迹后，点击“继续”。 |
| 4 | [发送第一条消息](04-first-message.zh.md) | 成功收到完整模型回复后推进。 |
| 5 | [查看练习轨迹](05-exercise-trajectory.zh.md) | 打开真实练习轨迹后，点击“继续”完成本章。 |

各小节维护自己的控件、前置条件和验收场景。章节导航、进度保存、重新开始及会话可见范围由共用需求维护。

## 对话上下文

示例和真实练习的系统提示词均为 `You are a helpful assistant`，完整使用这段文本。中英文界面都不改写，不添加标点或章节引导。示例请求和真实练习请求须采用同一提示词，并在各自轨迹的请求输入中展示。

## 章节验收

从一次新练习开始，依次完成五个小节；已有模型配置的用户也执行完整流程。覆盖人工点击推进和操作完成后推进，再验证贯穿整个流程的刷新、退出、再次进入和重新开始行为。

章节须区分静态对话及轨迹示例与用户的真实请求及记录。查看配置、示例或任一轨迹均不调用模型，只有真实练习由用户发送消息。成功收到完整回复后进入轨迹查看，实际打开该轨迹并明确点击继续才完成本章。

示例的输入框保持锁定。真实练习允许用户自由选择模型，仅将模型的 effort 固定在最低可选档位。验证切换模型后仍使用本章系统提示词，并按新选模型应用 effort 约束。
