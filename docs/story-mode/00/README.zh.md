# 第零章：hello world

[English](README.md) | 中文

第零章确立进入故事模式、跟随章节进度和完成练习的交互方式，同时约束章节专用体验与 PaperMoon 通用机制的职责边界。

## 体验

遵循[共用交互与实现约束](../README.zh.md)。本章名为 `hello world`。用户先阅读故事模式介绍，仅在没有配置齐备的模型时补全配置，再阅读预置的对话示例及其轨迹，随后在全新的练习对话中发送自己的消息，并查看这次真实对话的轨迹。

| 顺序 | 小节 | 推进方式 |
|---|---|---|
| 1 | [欢迎来到故事模式](01-introduction.zh.md) | 阅读介绍，至少一个模型配置齐备后，点击“继续”。 |
| 2 | [查看对话示例](02-conversation-example.zh.md) | 查看静态示例后，点击“继续”。 |
| 3 | [查看示例轨迹](03-example-trajectory.zh.md) | 查看原生示例轨迹后，点击侧栏中的“继续”。 |
| 4 | [发送第一条消息](04-first-message.zh.md) | 首次成功收到完整模型回复后推进，仍可继续对话。 |
| 5 | [查看练习轨迹](05-exercise-trajectory.zh.md) | 查看首次成功对话的原生轨迹后，点击侧栏中的“继续”完成本章，仍可继续对话。 |

各小节维护自己的控件、前置条件和验收场景。章节导航、进度保存、重新开始及会话可见范围由共用需求维护。

## 对话上下文

示例和真实练习的系统提示词均为 `You are a helpful assistant`，完整使用这段文本。中英文界面都不改写，不添加标点或章节引导。示例请求和真实练习请求须采用同一提示词，并在各自轨迹的请求输入中展示。

## 章节验收

从一次新练习开始，依次完成五个小节；已有模型配置的用户也执行完整流程，但不必查看配置页。第一节检查是否存在任意配置齐备的模型，未选默认模型或默认选择无效时同样适用。覆盖人工点击推进和操作完成后推进，再验证贯穿整个流程的刷新、退出、再次进入和重新开始行为。

章节须区分静态对话及轨迹示例与用户的真实请求及记录。查看配置、示例或任一轨迹均不调用模型，只有真实练习由用户发送消息。首次成功收到完整回复后进入轨迹小节，保留当前原生视图并允许继续发送消息。实际打开首次成功对话的轨迹并明确点击继续才完成本章。后续成功、失败、取消或中断均不改变查看目标或撤销进度，完成本章不关闭练习会话。

示例的输入框保持锁定。真实练习允许用户自由选择模型及其支持的 effort，按[第四节](04-first-message.zh.md#模型选择与-effort-提示)显示建议。验证切换模型后仍使用本章系统提示词，提示随当前模型和 effort 更新，且不会修改参数或阻止发送。
