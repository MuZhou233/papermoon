# 第零章第五节：查看练习轨迹

[English](05-exercise-trajectory.md) | 中文

本需求属于 [hello world](README.zh.md)，遵循[共用交互要求](../README.zh.md)。

## 体验与界面

首次成功收到完整回复后保留当前练习对话，使用共用定位提示引导用户选择原生“轨迹”标签。进入本小节不自动切换视图，章节进度和查看引导保留在侧栏。沿用[查看示例轨迹](03-example-trajectory.zh.md)介绍的检查交互。

本节查看目标固定为本次练习首次成功的对话。引导用户找到该次用户消息，查看对应请求的输入和模型参数，并将记录的输出与该次回复对应起来。有耗时和用量记录时，说明这些内容的含义。展示实际保存的数据，缺失字段保持不可用，不使用示例补齐。请求记录了 effort 时，引导用户找到实际值；没有记录时不推断其档位。不假定用户采纳了推荐档位。

引导用户同时查看[本章系统提示词](README.zh.md#对话上下文)。模型与 effort 读取被查看请求的记录，即使用户后来切换了模型选择器，也不改变这里展示的值。

轨迹读取与展示使用通用机制。查看操作只读，不重新发送请求、不切换执行历史，也不改变模型配置。打开轨迹不能替换练习会话，也不能使其出现在普通会话列表中。

本小节及完成本章后均可继续发送消息，遵循[练习的继续对话规则](04-first-message.zh.md#推进与恢复)。发送由原生请求状态控制，章节进度不额外锁定输入。后续消息、请求结果和模型选择都不替换首次成功对话这一查看目标，也不重置已满足的查看条件。

## 文本原文

侧栏引导使用：

> 选择对话上方的“轨迹”标签。找到本次练习中首次成功对话的记录，查看你的消息、请求使用的模型、系统提示词和回复。请求记录了 effort 时，也可以查看它的实际值；未记录时，不推断其档位。耗时表示请求花费的时间，用量表示记录的 token 数，只展示实际保存的数据。你可以继续对话，这不会改变本节的查看目标。

浮层使用[共用轨迹提示](../README.zh.md#轨迹浮层)，完成本章使用[章节概述中的文本](README.zh.md#章节文本)。记录标题、字段和控件复用 DSH 原生轨迹页面。消息、请求参数、耗时及用量来自已保存的首次成功对话，不使用预置或推断的值。

## 推进条件

只有本次练习首次成功对话的真实轨迹已打开并显示内容，才解锁侧栏中的“继续”。此前查看示例轨迹不满足本步骤的条件。记录缺失或无法读取时保持未完成，允许重新加载记录，不重新发送模型请求。

点击“继续”后完成本小节及整章，不关闭练习会话，也不停止正在进行的请求。显示章节完成状态，提供返回章节列表和重新开始的操作，同时允许继续对话。刷新或再次进入时保留本次练习的进度，仍查看同一份轨迹来源。

## 验收场景

- 真实回复结束后仍显示当前对话。显示或收起提示均不能完成步骤，用户打开原生轨迹后再查看。
- 轨迹展示当前练习的消息、请求及回复，包括完整的本章系统提示词、请求实际采用的模型及适用的 effort。后续模型选择不改写这些记录值，也不替换为示例或其他会话内容。
- 记录详情展示已有的耗时和用量，缺失值不补造。
- 打开、刷新及重新加载轨迹均不调用模型，也不改变对话或模型配置。
- 只有首次成功对话的真实轨迹实际显示后才解锁“继续”；点击后完成章节并提供返回及重新开始操作，不关闭对话或停止正在进行的请求。
- 本小节及章节完成后仍可输入和发送。后续成功、失败、取消或中断不改变查看目标、不撤销查看结果，也不撤销章节进度。
- 刷新及重新进入保留同一练习会话，并继续以首次成功对话为查看来源；恢复请求状态不自动发送。
