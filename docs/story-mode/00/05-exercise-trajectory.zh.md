# 第零章第五节：查看练习轨迹

[English](05-exercise-trajectory.md) | 中文

本需求属于 [hello world](README.zh.md)，遵循[共用交互要求](../README.zh.md)。

## 体验与界面

成功收到回复后，引导用户打开同一练习会话的“轨迹”。提供直达上一小节成功对话的入口，保留章节进度及返回该对话的方式。沿用[查看示例轨迹](03-example-trajectory.zh.md)介绍的检查交互。

引导用户找到自己发送的消息，查看对应请求的输入和模型参数，并将记录的输出与刚才收到的回复对应起来。有耗时和用量记录时，说明这些内容的含义。展示实际保存的数据，缺失字段保持不可用，不使用示例补齐。模型支持 effort 时，引导用户找到本次请求使用的最低档位；不支持时，说明请求没有 effort 参数。

引导用户同时查看[本章系统提示词](README.zh.md#对话上下文)。模型与 effort 读取被查看请求的记录，即使用户后来切换了模型选择器，也不改变这里展示的值。

轨迹读取与展示使用通用机制。查看操作只读，不重新发送请求、不切换执行历史，也不改变模型配置。打开轨迹不能替换练习会话，也不能使其出现在普通会话列表中。

## 推进条件

只有本次成功对话的真实轨迹已打开并显示内容，才解锁“继续”。此前查看示例轨迹不满足本步骤的条件。记录缺失或无法读取时保持未完成，允许重新加载记录，不重新发送模型请求。

点击“继续”后完成本小节及整章，显示章节完成状态，并提供返回章节列表和重新开始的操作。刷新或再次进入时保留本次练习的进度，仍查看同一份轨迹来源。

## 验收场景

- 真实回复结束后进入轨迹查看，不立即完成章节。
- 轨迹展示当前练习的消息、请求及回复，包括完整的本章系统提示词、请求实际采用的模型及适用的 effort。后续模型选择不改写这些记录值，也不替换为示例或其他会话内容。
- 记录详情展示已有的耗时和用量，缺失值不补造。
- 打开、刷新及重新加载轨迹均不调用模型，也不改变对话或模型配置。
- 只有打开本次真实轨迹后才解锁“继续”；点击后完成章节，并提供返回及重新开始操作。
