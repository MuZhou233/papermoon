# 第零章第四节：发送第一条消息

[English](04-first-message.md) | 中文

本需求属于 [hello world](README.zh.md)，遵循[共用交互要求](../README.zh.md)。

## 体验与界面

本次练习首次到达此步骤时，创建没有既有对话历史的新练习会话，采用[本章系统提示词](README.zh.md#对话上下文)。不复用普通对话，也不插入上一节的示例。恢复本次练习时使用其已有练习会话，不另建会话。

引导用户输入任意非空文本并发送。显示模型选择器、模型支持的 effort 控件、文本输入、发送／停止及展示回复所需控件，允许用户自由选择已配置的可用模型及其支持的 effort。不提供工具、附件或模式切换。使用真实的 DSH 对话页面及其原生输入框、模型控件和消息渲染，真实请求与会话持久化使用通用机制。

## 模型选择与 effort 提示

初始沿用有效的当前模型选择。没有有效选择时，由用户通过原生选择器选择配置齐备的模型后发送，第一节的配置检查不替用户选择模型。练习期间允许更换模型及其支持的 effort。在侧栏聚焦的小节中，根据当前模型的能力和生效 effort 显示提示；适用时将明确声明的模型默认值计入判断：

- 模型支持 `off` 时，只有当前生效档位可确认为 `off`，才隐藏提示；否则提示用户选择 `off`。不能仅因参数未填写就认定已关闭思考。
- 模型不支持 `off` 时，始终提示使用最低档，即使用户已选择最低档也保留提示。不推断或校验哪个选项最低。

模型或 effort 改变后更新提示。提示只提供建议，不锁定控件、不自动选择档位、不覆盖请求参数，也不阻止发送或章节推进。模型没有 effort 配置时保留提示，并说明没有可调档位；不提供 effort 控件，也不传该参数或沿用上一模型的 effort。

切换模型后仍使用本章系统提示词。模型与 effort 选择仅作用于章节练习，不改写普通会话或全局默认的模型与 effort 选择。

## 文本原文

原生练习输入框使用以下占位文字：

> 输入消息

侧栏引导使用：

> 发送任意非空文本。你可以自由选择模型和 effort。收到第一条完整回复后进入下一步，也可以继续对话。

| effort 情况 | 原文 |
|---|---|
| 支持 off，但未确认为 off | 本次练习建议选择 off，关闭思考。 |
| 不支持 off | 本次练习建议使用最低 effort 档位。 |
| 没有可调档位 | 本次练习建议使用最低 effort 档位。当前模型没有可调节的 effort 设置。 |

请求未完成时使用：

> 上次请求未完成，可以重试。打开页面不会自动重发请求。

模型名称和 effort 选项来自 DSH 模型元数据与原生控件。用户消息、模型回复和底层请求错误来自真实练习，不属于预置章节文本。[章节概述](README.zh.md#章节文本)维护练习标题，[对话上下文](README.zh.md#对话上下文)维护系统提示词。

## 推进与恢复

只有用户消息首次成功收到完整模型回复，才进入[查看练习轨迹](05-exercise-trajectory.zh.md)。仅提交消息或收到部分回复均不算完成本步骤。请求失败、取消或中断时，保留进度，显示请求结果并允许用户重试。恢复页面不自动重发请求。

首次成功回复完成本小节，并固定下一节的查看目标。保留同一练习会话及当前原生视图，不自动切换轨迹。进入第五节及完成本章都不因章节进度锁定输入框或禁止发送；用户仍可在原生对话视图编辑和发送，遵循原生请求状态控制。

模型和 effort 仍可自由选择。章节活动期间，本章系统提示词及工具、附件、模式切换限制继续生效。后续成功、失败、取消或中断既不替换首次成功对话这一查看目标，也不撤销进度或重置已满足的查看条件。恢复页面始终不自动重发请求。

完成本章不关闭练习会话。离开、重新进入、重新开始及关闭故事模式遵循共用生命周期要求。练习通过故事模式恢复，不进入普通会话列表。

## 验收场景

- 新练习使用完整的本章系统提示词，历史和请求上下文中均没有普通会话或示例消息；恢复同一次练习时保留其自身消息。
- 用户可以提交任意非空文本，并自由选择可用模型及其支持的 effort。当前没有有效选择时，须通过原生选择器选择配置齐备的模型后发送，介绍步骤不会自动代选。
- 模型支持 `off` 时，选择其他档位会显示建议，选择 `off` 后隐藏。明确声明为 `off` 的模型默认值也满足条件；没有这个默认值时，仅省略参数不满足条件。
- 模型不支持 `off` 时，无论当前选择哪个档位，都保留使用最低档的提示。模型没有 effort 配置时，额外说明没有可调档位。
- 切换模型或 effort 后更新提示，不自动选用推荐档位。请求仍采用本章系统提示词并遵循用户选择；切换到不支持 effort 的模型时移除该参数。
- 提示显示时仍可发送，成功收到完整回复后仍会推进。模型与 effort 选择不改变普通会话和全局默认值。
- 首次成功收到完整回复后进入同一会话的轨迹小节，保留当前原生视图；仅提交、部分回复、失败、取消和中断均不推进。用户仍可重试，刷新不自动重发。
- 首条完整回复后、轨迹小节中及完成本章后，输入和发送都保持可用，遵循原生请求状态控制。模型和 effort 仍可自由选择，提示词及章节限制保持一致。
- 后续成功或失败不替换首次成功轨迹目标、不重置已满足的查看条件，也不撤销进度。刷新及重新进入保留会话和这些结果，不重发请求。
- 最后一个小节完成前，章节保持未完成；练习会话不出现在普通列表。
