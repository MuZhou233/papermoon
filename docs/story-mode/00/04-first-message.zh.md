# 第零章第四节：发送第一条消息

[English](04-first-message.md) | 中文

本需求属于 [hello world](README.zh.md)，遵循[共用交互要求](../README.zh.md)。

## 体验与界面

本次练习首次到达此步骤时，创建没有既有对话历史的新练习会话，采用[本章系统提示词](README.zh.md#对话上下文)。不复用普通对话，也不插入上一节的示例。恢复本次练习时使用其已有练习会话，不另建会话。

引导用户输入任意非空文本并发送。显示模型选择器、文本输入、发送／停止及展示回复所需控件，允许用户自由选择已配置的可用模型，不提供工具、附件、模式或 effort 切换。界面沿用 DSH 的视觉风格，真实请求与会话持久化使用通用机制。

## 模型与 effort 约束

初始使用第一节选定的模型，练习期间允许更换。模型选择控件仅锁定 effort，将其固定为当前模型的最低可选档位。每次切换模型后重新确定最低档位，不沿用上一模型的 effort。如果关闭思考属于可选 effort 档位，选择最低值时也包括该选项。模型没有 effort 配置时不传该参数，也不保留上一模型的 effort。

这项选择必须在真实练习请求中生效，不能只改变控件显示。切换模型后仍使用本章系统提示词。模型选择与 effort 约束仅作用于章节练习，不改写普通会话或全局默认的模型与 effort 选择。

## 推进与恢复

只有用户消息成功收到完整模型回复，才进入[查看练习轨迹](05-exercise-trajectory.zh.md)。仅提交消息或收到部分回复均不算完成本步骤。请求失败、取消或中断时，保留进度，显示请求结果并允许用户重试。恢复页面不自动重发请求。

成功回复只完成本小节，章节继续推进，下一步保留同一个练习会话。遵循共用的进度与会话可见范围要求：练习通过故事模式恢复，不进入普通会话列表。

## 验收场景

- 新练习使用完整的本章系统提示词，历史和请求上下文中均没有普通会话或示例消息；恢复同一次练习时保留其自身消息。
- 用户可以提交任意非空文本，并自由选择可用模型；模型选择器可操作，没有 effort 切换入口。
- 切换模型后，实际请求仍采用本章系统提示词，并使用新模型支持的最低 effort，包含可用的关闭思考选项；切换到不支持 effort 的模型时移除该参数。
- 模型选择及练习的 effort 约束不改变普通会话和全局默认值。
- 成功收到完整回复后进入同一会话的轨迹查看；仅提交、部分回复、失败、取消和中断均不推进。用户仍可重试，刷新不自动重发。
- 最后一个小节完成前，章节保持未完成；练习会话不出现在普通列表。
