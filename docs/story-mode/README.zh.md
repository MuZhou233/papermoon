# 故事模式需求

[English](README.md) | 中文

故事模式（Story Mode）按章节组织体验。这些文档定义预期体验及其约束。开发与交付继续沿用现有流程。

## 文档组织

每章使用带编号的目录，以 README 说明目标和步骤顺序，每小节使用带编号的独立 Markdown 文件。按[文档规则](../AGENTS.md)维护英文、中文和配对文件。

每个小节记录用户操作、可观察结果、所需的 UI 和引导、推进条件及验收场景。本入口文档维护共用交互要求，各章引用，不重复定义。需求文档不记录实现或交付状态。架构、API 和实现决策由工程文档及 Agent Notes 维护。

## 文本依据

故事模式提供或改写的所有文本，都必须在需求文档中给出明确原文，包括名称、介绍、引导、控件、状态、异常提示、示例消息和预置提示词。共用文本由本文维护；章节文本由章节概述或所属小节维护，其他文档引用，不重复维护。中英文界面分别使用确认的译文；声明为固定原文的提示词和示例消息不随界面语言翻译。

缺少所需文本时，先讨论措辞并补齐需求，再实现相关内容。已有代码中的文本不自动视为已确认需求。文本及翻译需要调整时，先讨论并更新需求，再进行实现。禁止在实现过程中自行增补、润色、缩写或替换已确认原文。

动态文本须给出完整模板及各变量的来源。原样复用的 DSH 控件注明来源，不重复抄录上游文案。模型名称来自模型元数据，真实回复来自练习会话，底层实际错误来自产生错误的服务。故事模式围绕这些数据新增的提示仍须给出明确模板；故事模式自己生成的固定错误使用下方原文。

## 共用交互

### 入口与章节导航

左侧栏增加“故事模式”入口。页面显示章节列表、各章完成状态和进入按钮。进入章节后，将侧栏原工作区列表区域替换为章节进度，区分已完成、当前和未开始的步骤。点击进度列表不能跳过未完成的步骤。

提供返回章节列表的入口，离开章节时恢复普通工作区列表。章节激活期间，新建会话入口不能绕过当前步骤或创建普通会话。

沿用 DSH 的主题、排版、控件和响应式习惯。章节内的对话与轨迹使用真实的 DSH 页面，不另建章节专用渲染界面。操作引导、前置条件反馈及“继续”放在左侧栏，仅在聚焦的小节展开引导。小节可以明确要求在主体展示介绍，操作引导仍放在侧栏；其他步骤只显示标题和进度状态。示例与练习会话通过正常导航进入默认对话页面，保留原生顶栏、标签、消息、输入框和响应式布局，仅按当前小节要求施加变化。章节活动状态独立于已选面板或视图。配置页面可从章节中打开，关闭后回到原步骤，不丢失进度。私有会话也应显示可读标题。离开或关闭故事模式时释放限制和引导，不改变普通会话及全局默认值。

轨迹步骤保留当前对话，引导用户选择原生“轨迹”标签。章节会话临时开放该标签，不修改全局开发者设置。定位浮层突出真实控件并给出简短提示，完整引导保留在侧栏。浮层跟随滚动和布局变化，等待目标挂载且可见，保留原生鼠标和键盘操作；不模拟点击，也不提供另一个切换入口。Escape 收起提示，侧栏操作可重新显示。收起提示不满足查看条件。刷新后按真实页面状态恢复，对应轨迹已经显示时无需重复提示。

### 推进方式

支持两类推进条件：用户操作产生的可验证结果，以及用户明确点击继续。每个小节规定自己的条件。人工推进的步骤如有前置条件，满足后只解锁“继续”，不自动前进。

### 保存进度与重新开始

同一安装配置下保存章节进度和练习会话，刷新、退出及再次进入时继续本次练习。“重新开始”重置本次进度，真实对话练习使用没有既有对话历史的新会话。练习会话仅通过故事模式恢复，不出现在普通会话列表中。

恢复页面不自动重发模型请求。请求失败、取消或中断时保留练习，允许用户重试。章节完成后明确显示完成状态，提供返回章节列表和重新开始的操作。

## 实现约束

遵循[架构职责](../architecture.zh.md#职责)：故事模式插件负责章节定义、进度编排、章节导航、侧栏引导和预置内容；模型配置、请求执行、会话持久化等通用机制由其他包提供。优先通过这些机制的公开扩展点接入。必要的 DSH 补丁遵循[补丁范围规则](../../patches/README.zh.md)，尽量缩小范围，确需扩大时说明理由。

后续章节需要调整架构时，所有已实现章节仍须能在当前版本从头完成。操作说明和预置内容须先讨论文本并更新需求，再作调整，同时保留教学目标与预期结果。保存进度不意味着支持旧进度或旧会话格式的迁移。

## 共用验收场景

- 侧栏入口打开章节列表，显示完成状态及进入按钮；进入和离开章节时，工作区列表区域正确替换与恢复。
- 仅聚焦的小节展开侧栏引导，对话与轨迹步骤使用真实的 DSH 页面。
- 进度区分已完成、当前和未开始步骤；进度列表和新建会话入口均不能绕过规定顺序。
- 打开、关闭配置页后仍停留在原步骤；宽屏和窄屏界面均沿用 DSH 风格。
- 刷新或再次进入恢复本次进度和练习会话；重新开始重置进度，并为真实练习使用全新对话。
- 练习会话不出现在普通列表，恢复页面不重发请求。
- 所有故事模式文本均能对应所属需求原文、明确模板或记录的复用／数据来源；缺少措辞时先讨论再实现，实现不改写已确认文本。
