# 剧情模式需求

[English](README.md) | 中文

剧情模式按章节组织体验。每个小节的 Markdown 文档记录预期体验，并作为该小节的产品需求。开发与交付继续沿用现有流程。

## 文档组织

每章使用带编号的目录，每小节使用带编号的独立 Markdown 文件，按[文档规则](../AGENTS.md)维护英文、中文和配对文件。小节可以先于功能编写，其中的需求不代表体验已经交付。

小节描述用户操作、可观察结果及所需的 UI 和引导，包括逐步出现的控件或专用界面。跨小节共用的体验要求集中在一份文档中，由相关小节引用。架构、API 和实现决策由工程文档及 Agent Notes 维护。

后续章节需要调整架构时，所有已实现章节仍须能在当前版本从头完成。操作说明和预置内容可以更新，同时保留教学目标与预期结果。这项要求不规定旧练习、进度或会话的迁移支持。
