# 第一章：第一个角色

[English](README.md) | 中文

本章是[雾锁地照](../README.zh.md)的起点。用户先理解输入与回复，再认识消息和上下文，编写开场与系统提示词，最后选择模型和思考强度，开始第一次演绎。遵循[存档设计](../../design.zh.md)、[共用交互](../../README.zh.md#共用交互)及[创作能力](../../../playbook-authoring.zh.md)。

## 学习顺序与能力

五节沿概念的前置关系展开：输入怎样影响生成，消息怎样组成上下文，系统要求怎样参与交流，内容安排为何随模型产生不同效果，以及怎样观察实际演绎。每节先独立说明概念、机制与实践建议，再由示例及分析承接讲解，最后提供操作引导。

初始系统提示词为空，开场消息为零条。示例属于阅读材料，存档保留空白创作起点。本章两个部分都使用纯文本模式，脚本编辑及创作模式切换保持关闭。

| 节 | 新开放的内容 | 推进方式 |
|---|---|---|
| [1.1 提示词与回复](01-prompts-and-replies.zh.md) | 阅读讲解和书面示例，创作内容读写范围为空。 | 手动继续。 |
| [1.2 消息与上下文](02-messages-and-context.zh.md) | 手动或通过编剧读取和编辑开场消息，包括正文、角色和顺序。 | 保存当前开场设置后手动继续，允许空列表。 |
| [1.3 系统提示词与角色设定](03-system-prompts-and-character-design.zh.md) | 增加系统提示词读取和编辑，保留开场编辑。 | 保存包含非空白文本的系统提示词后手动继续。 |
| [1.4 内容安排与模型差异](04-content-placement-and-model-differences.zh.md) | 开放模型选择，保留两个纯文本编辑器。 | 选定有效模型后手动继续。 |
| [1.5 思考强度与第一次演绎](05-reasoning-effort-and-first-performance.zh.md) | 选择支持的思考强度，启动演绎。 | 首次成功收到完整模型回复，并保存对应章节提交。 |

完整讲解与示例保留在右侧，中央提供当前已开放的操作。用户可以边阅读边操作，需要定位控件时使用简短浮层。1.1 的继续操作只记录本节推进，阅读不设时长、滚动或答题条件。内容编辑能力在后续节保持可用，1.4 的内容调整和比较尝试属于可选实践。

编剧保存与人工保存满足相同内容条件，继续仍由用户操作。继续或启动前先处理待保存修改，保留未解决的本地内容。1.3 检查系统提示词的非空白条件，启动演绎前再次检查。模型配置和选择沿用原生机制，选择用于本次演绎，全局默认值保持原样。

上表同时规定人工与编剧的内容权限。1.1 的创作内容读写范围为空；1.2 只开放开场消息；1.3 至 1.5 同时开放开场消息和系统提示词。通用状态、帮助、历史和元数据入口遵守同一范围。已有编剧会话随解锁更新工具，恢复、Fork 和每次执行重新校验当前权限。本章的程序、文案目录、历史恢复、编译和进度编辑工具保持关闭。模型配置由用户通过原生入口管理，供已开放功能使用。当前存档的演绎模型选择在 1.4 开放，思考强度选择与演绎启动在 1.5 开放；通用入口遵守相同阶段范围。

## 贯穿示例

本节统一维护跨节复用的原有示例原文，各节专用示例由所属节维护。各节按自己的展示说明引用对应部分，示例及分析位于讲解之后。展示示例不会填入 Playbook、请求模型或满足章节回复条件。原文采用当前界面语言的对应版本。

### 角色设定

> 你扮演住在雾港边的守灯人。说话简短、平静，描述你能看见和听见的事物。访客问起你不了解的事情时，坦诚说明，并问问对方发现了什么。

### 开场消息

| 角色 | 正文 |
|---|---|
| 用户（user） | 暮色落在港口。我拿着一张潮湿的地图，走到灯塔门前。 |
| 助手（assistant） | 守灯人将门推开一道缝：“先进来吧。是什么事让你在这种雾里赶路？” |

### 首次输入

> 我把地图摊在桌上。你以前见过这个标记吗？

## 章节文本

章名为“第一个角色”，节名称采用顺序表标签。共用控件采用以下原文，遵循[文本依据规则](../../README.zh.md#文本依据)。引导面板、提醒和浮层控件采用[共用界面文本](../../README.zh.md#共用界面文本)。保存及其他编辑控件复用通用编辑器，模型与对话控件复用原生页面。

| 用途 | 文案 |
|---|---|
| 人工推进 | 继续 |
| 启动 | 开始演绎 |
| 留在对话中 | 继续对话 |
| 下一章 | 进入第二章 |
| 下一章未开放 | 第二章尚未开放，你可以继续对话。 |

## 完成与继续

[第五节](05-reasoning-effort-and-first-performance.zh.md#启动与完成条件)维护成功回复条件与提交行为。提交成功后完成第一章，创建章节标签（tag），并按共用存档规则开放只读章节回顾。章节完成依据仍为合格回复与可靠提交，模型比较和内容调整属于创作选择。

完成后保持演绎开启。用户可以继续对话，或在第二章开放时进入。第二章尚未开放时显示说明并禁用入口。第二章内容由后续需求维护。

## 验收场景

- 从空白内容开始，依次完成五节，覆盖手动编辑、编剧协助及两者结合；示例逐节承接讲解，讲解可独立阅读。
- 在右侧阅读完整讲解与示例，同时在中央创作或对话；浮层定位真实控件，未查看的进度更新按共用规则提醒，保持当前焦点。
- 1.1 不开放创作读写；1.2 只允许开场内容；1.3 增加系统提示词。编辑器、工具、状态和帮助遵守相同范围，已有会话随解锁更新，拒绝旧调用与间接越权访问。
- 允许空开场列表；1.3 推进和 1.5 启动要求非空白系统提示词，普通草稿存储继续允许未完成内容。
- 1.4 保留原有内容即可选择模型并继续，比较尝试和多次回复不成为通过门槛；提前启动演绎的通用入口受阶段约束。
- 合格回复和带章节标签的提交可靠保存后完成，后续对话与只读回顾保留当前进度。
- 第二章开放后才允许进入，关闭的入口保留明确说明。
