# 定位提示

[English](README.md) | 中文

本扩展提供根作用域的 `anchored-guidance` UI 工厂，通过稳定的 DOM 选择器突出真实控件，并在旁边显示简短提示。消费者负责目标、本地化文案、关闭按钮名称及 `onDismiss` 回调，按自身流程挂载或卸载工厂。扩展不感知章节或完成条件。

浮层跟随目标的位置、滚动和窗口尺寸变化，目标缺失、隐藏或被遮挡时等待。它不点击、不移动焦点，也不替代控件。高亮边框允许指针操作穿透，提示框的关闭按钮和 Escape 调用 `onDismiss`。显示期间，提示为目标添加自己的 `aria-describedby` 标记，清理时只移除该标记。消费者可在收起后重新挂载提示。

Client 还导出 `observeVisibleTarget(target, visible)`，在动画帧中查找当前 DOM 目标。只有目标在视口内具有可见区域，且该区域通过命中检测时，才调用 `visible`。隐藏的文档、裁剪、浮层遮挡以及未挂载的虚拟列表行都不能满足条件。返回的释放函数停止观察。消费者须防止重复回调产生重复操作，并维护确认状态；观察器不会根据生成的数据推断操作已完成。

扩展没有 Host 状态，独立于故事模式。故事模式浏览器测试在实际托管的 DSH 页面中验证定位、原生键盘操作、收起、恢复和插件卸载。
