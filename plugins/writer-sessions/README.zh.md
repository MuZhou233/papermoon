# 编剧会话

[English](README.md) | 中文

## 使用

选择编剧模式、剧本工作区和编剧。模型与推理档位沿用 DSH 设置。首条输入被持久接纳后，剧本、模式和完整编剧快照随之固定，模型调用失败或取消也不会解除固定。修改或删除编剧配置不影响已接纳的对话。冻结后的编剧选择器显示在会话顶部。剧本工作区只显示剧本名，选择剧本时同时显示项目名，便于区分同名剧本。

## 上下文与审查

系统提示词与有序的 user／assistant 消息按原文发送，名称只用于审查。对话将起始消息折叠为一个可展开条目，轨迹逐条显示真实角色。请求从日志重建，不读取最新编剧配置。显式插件仍可贡献有记录的上下文。编剧组合不装配编码、文件系统、压缩或结果落盘插件。

## 职责

插件维护已认证的配置操作及 Agent 独立工具。准备状态保存为 session/configuration 记录，已接纳输入通过 source.admission 携带快照。Fork 继承快照与预置消息身份。恢复和 Fork 都建立新的工具注册与读取记录。剧本 ID 是资源引用，不作目录路径使用；进程 cwd 来自插件配置。

多个对话和人工编辑器可以编辑同一剧本。局部编辑工具要求有效的对象读取记录，不要求模型提供草稿序号。不同会话可以分别保存互不影响的文件和译文。提交、恢复和删除语言保留明确的快照校验，具体规则与保存重试见[工具文档](../story-tools/README.zh.md#会话读取记录)。列表、搜索、历史读取和浏览器预览不授予修改权限。显式恢复和删除语言按声明范围替换，并清除受影响的记录。删除剧本后保留对话历史，但禁止继续输入和调用工具。删除工作区登记不会删除剧本。

## 检查

执行 `pnpm check`、`pnpm build:plugins`、`pnpm check:plugins:dsh` 和 `pnpm test:writer-sessions`。集成使用独立数据、真实 DSH 组件与确定性模型适配器。通用 DSH 补丁提供资源目标、消息接纳、预置记录及客户端扩展位置，产品规则留在本插件。

profile 将[编译服务](../story-compiler/README.zh.md)明确传入会话工具构建过程。编译使用绑定剧本，通过 DSH 工具记录完整回执，不改变起始提示词或读取观察。

[共用剧本工作区提供者](../story-workspaces/README.zh.md)负责资源登记，将编剧与[演绎](../performances/README.zh.md)会话放在同一工作区。本包继续负责编剧准备状态与固定上下文，两种预设不替换对方的配置或 scope 贡献。
