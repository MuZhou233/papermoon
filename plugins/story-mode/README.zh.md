# 故事模式插件

[English](README.md) | 中文

这个可开关的组合包实现[第零章：hello world](../../docs/story-mode/00/README.zh.md)。需求由章节文档维护，本文说明插件边界与使用方式。

## 职责

插件负责五步章节、引导、固定示例、effort 提示和进度条件。它使用[文本对话扩展](../text-conversations/README.zh.md)、[定位提示扩展](../ui-guidance/README.zh.md)、DSH 设置导航和原生对话页面。通用模型配置、Agent 执行、会话持久化及轨迹渲染仍由下层提供。

进度以原子写入方式保存在 `$DSH_HOME/story-mode/hello-world.json`。重新开始后，尝试 ID 会拒绝旧页面提交的操作。练习在第四步分配全新的 DSH Session；重新开始会保留原会话文件，但不会复用。进度引用练习会话，不复制日志。不支持的进度会明确失败，不修改原文件。

客户端仅在章节内通过现有插槽优先级机制替换侧栏工作区区域。随插件生命周期注册的新建会话处理器将用户带回当前步骤。侧栏仅在聚焦的小节展开引导和“继续”。主体展示介绍，提供可自行选择使用的设置按钮。推进只要求至少一个模型配置齐备，不依赖默认选择，也不要求查看设置。读取失败时不能推进，可以重试而不丢失当前练习。检查不调用模型，也不替用户选择模型。新练习沿用有效的当前选择，否则由用户通过原生控件选择。

示例与练习通过正常 Session 导航进入默认对话页面，沿用顶栏与标签。章节活动状态独立于当前面板，打开设置或切换视图不会退出章节，也不会触发反复导航。固定示例使用独立的只读 Session 种子，不调用模型、不复制到练习历史，也不编造用量。查看轨迹期间及完成本章后，练习都可继续发送消息。首次完成的回合确定查看目标，后续回复、失败和取消不会更换目标或撤销进度。完成章节不会停止 Agent。

两个轨迹步骤保留当前视图，并突出显示原生“轨迹”标签。用户自行选择标签，目标回复对应的原生记录行实际可见后才解锁“继续”。后续回复、后台投影、隐藏或被虚拟列表移除的记录都不能确认目标已查看。Escape 收起提示，侧栏可重新显示。按会话和所属插件管理的约束临时开放轨迹入口，限制工具、附件和模式控件，不改变开发者设置或模型默认值。离开或卸载时释放约束、已选中的私有页面及全部引导。

`src/locales.ts` 保存需求确认的文案，供 Host 和 Client 共用。故事模式 RPC 失败携带稳定键用于本地化，底层错误保留原始消息。文案测试逐项核对对应语言的需求原文，包括固定提示词和示例消息。调整措辞须先更新需求。

## 开启与关闭

`pnpm start` 初始化 PaperMoon profile 时默认开启此组合包。可以在 DSH 插件页关闭或重新开启。关闭后组合包仍已安装并显示在列表中，后续启动保留选择。卸载会停止并等待所属练习 Agent 退出，移除界面，保留进度。重新开启不会重发输入。文本对话扩展独立保持挂载。

## 验证

`pnpm test:story-mode` 使用确定性模型适配器和临时数据运行完整应用，覆盖配置可用性及恢复、无效默认选择、两次轨迹检查、实际请求、完成后继续对话、effort 提示、失败、停止、刷新及重新开始，不使用真实模型凭据。
