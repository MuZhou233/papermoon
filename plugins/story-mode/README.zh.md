# 故事模式插件

[English](README.md) | 中文

故事模式实现[雾锁地照](../../docs/story-mode/fogbound-earthshine/README.zh.md)，从“第一个角色”的五节开始。每份存档都是独立绑定故事线的 Playbook，故事入口与普通 Playbook 列表共用这些存档。[共用需求](../../docs/story-mode/design.zh.md)维护产品行为，[章节需求](../../docs/story-mode/fogbound-earthshine/01/README.zh.md)维护双语讲解与界面原文。

## 职责

插件提供故事线内容、阶段策略和流程编排。`papermoonPlaybookCore` 为所有使用方解析能力范围，`papermoonPerformances` 负责模型选择、执行及持久会话记录。右侧栏提供页面和会话承载，[定位提示](../ui-guidance/README.zh.md)指向真实控件。普通左侧导航保持可用。

Playbook 草稿受保护的 `$managed` 元数据保存故事线绑定、当前节与步骤、完成状态及演绎会话引用。注册的策略在 1.2 开放开场消息，1.3 开放系统正文，1.4 开放模型选择，1.5 开放演绎。编辑器和编剧保存均满足相同内容条件，1.1–1.4 由用户明确继续。第一章关闭复制、恢复、模式切换、脚本及普通提交入口。策略提供方卸载后，受保护操作暂停。

## 启动、提交与回顾

启动将已保存内容提交为普通的无章节 tag 版本，并冻结编译产物与双语教学。预留的演绎 Session 保存模型与思考强度选择，选择仅作用于当前会话。重复启动复用该会话与版本，展示预置开场时不请求模型。

首条已持久化、完整成功且含模型正文的回复满足本章条件。存储事务从启动版本创建章节版本，附加唯一的 `story/fogbound-earthshine/chapter/1` tag，并推进受保护进度。后续草稿修改完整保留。提交失败时保持未完成，重试使用已保存回复。重复事件和请求获得同一章节结果。

只读回顾载入章节内容与教学，并按引用读取截至成功回合的世界线记录范围。后续对话位于该范围之外，记录缺失时显示错误。关闭回顾返回当前进度，执行仍由演绎模块负责。章节完成后保留对话，第二章入口保持禁用并显示开放状态。

## 接口与展示

认证后的 `papermoon-story/*` RPC 提供 `catalog`、`list`、`create`、`state`、`models`、`choose`、`advance`、`start`、`retry`、`review` 和 `context`。写操作按 Playbook 串行编排，核心写入保留序号检查。`context` 解析编辑页及真实编剧／演绎关联。编辑器提供中央模型控件面板和引导所需的页面上下文。

引导跟随该上下文穿行于编辑器与所属会话。新建时右栏保持收起，可关闭的浮层锚定展开按钮，引导展示后清除浮层；主动继续时展开引导。进度更新保留当前工具、焦点与宽度。收起时在展开按钮左侧显示未查看更新提醒；其他工具被选中时，引导标签显示圆点。最新内容展示后清除提醒。按存档保存的阅读与已查看偏好属于展示状态。窄屏使用共用全屏承载，定位外部操作后提供返回入口。

入口与引导采用 DSH 主题变量和共用控件。紧凑的顶部和底部为滚动正文保留空间，正文承载讲解、分析与操作引导。示例使用共用 `PromptTrace` 轨迹表格和原文详情，显示标签采用所属教学术语。中央能力标签及编辑器强调标明新开放的开场、系统、模型与演绎控件，持续至对应结果保存或演绎启动。这些提示从现有存档状态派生。

`src/content.ts` 保留需求中的讲解、示例、分析、操作提示及状态文案。`tests/content.spec.ts` 将这些文本与当前五节需求核对。其他界面标签由 `src/locales.ts` 维护。

## 启用与关闭

PaperMoon 配置默认启用此组合包，插件页保存用户选择。卸载会移除引导与策略注册，Playbook 数据和模块所属会话继续保存，受保护操作等待提供方恢复。存储遵循[当前格式政策](../../docs/development.zh.md#冻结修订数据)，现有运行文件保留原样。

## 验证

主库测试覆盖权限、存档隔离、启动恢复、提交失败与幂等。`pnpm test:story-mode` 使用临时数据和确定性适配器运行真实 DSH 应用，检查五节流程、实际系统正文与消息顺序、启动时无推理请求、后续草稿保留、有界回顾、刷新、新建浮层、轨迹示例选择、能力提示、收起提醒及窄屏定位。编辑器和编剧会话套件验证共用创作与对话行为。
