# 共用剧本工作区

[English](README.md) | 中文

papermoon-script 提供者按稳定剧本身份组织[编剧](../writer-sessions/README.zh.md)和[演绎](../performances/README.zh.md)会话。它分别解析剧本名称与配置中的绝对进程 cwd，剧本 ID 不作为文件路径。

StoryWorkspaces 登记使用方提供的会话读取函数，从运行中或持久记录校验归属，列举剧本选项并刷新工作区标题。使用方通过 effect 登记，清理时移除读取函数。本插件负责唯一的提供者注册，会话插件分别管理准备状态与冻结配置。

删除工作区登记不会删除剧本。已删除剧本不能提供新目标，但保留的会话记录仍可识别所属工作区。源剧本缺失后能否继续，由各会话使用方决定。默认组合先挂载存储与核心，再挂载本提供者和两个使用方。
