# 文本演绎

[English](README.md) | 中文

本插件读取修订版本冻结的开场产物，创建主持人对话。它依赖[修订产物读取器](../story-compiler/README.zh.md)、文本运行时和[共用剧本工作区](../story-workspaces/README.zh.md)，不导入编译执行入口或 Worker。开始对话不会调用模型。

## 开始与继续

总览、修订版本页面和演绎模式共用启动对话框。未指定历史版本时，选择编号最大的修订版本，并默认使用其第一项冻结结果。最新版本没有产物时禁用启动，不改选较早的可用版本。模型目录和默认值来自 DSH。

初始化记录保存剧本与修订版本身份、名称、说明、附件键、完整产物、原始会话身份和完整性哈希。稳定会话 ID 使重试保持幂等，源剧本删除后也适用。初始化未完成或已损坏时拒绝输入。版本、产物和模式固定后不能改选，更换语言或版本需要另开对话。

预置 assistant 文本显示为开场正文，预置 user 文本显示为背景资料。名称与生产者标签不进入消息正文，系统文本可展开检查。空消息和重复角色均保留。第一条真实用户消息触发模型调用，DSH 记录起始消息的真实角色，供请求重建使用，不伪造模型调用或用量。初始化与后续预置上下文记录共用稳定展示身份，刷新、分页和复制保持一致。

主持人组合不包含剧本工具、编码指导、自动压缩或结果落盘裁剪。其他明确挂载的插件通过常规扩展点贡献内容并完整记录。Fork 和恢复使用已保存初始化资料，源剧本删除后仍可继续。原附件损坏会阻止新演绎启动，但不影响已有会话的完整副本。会话副本损坏时明确失败，两条路径都不重编译或修复数据。

## 接口与生命周期

/api/papermoon-performances 下的认证路由提供 scripts、models、choices、state 和 start，Performances 提供相同的内部操作。注册、接纳校验和各 Agent 的提示词贡献均由 effect 管理。关闭服务时先等待正在初始化的操作，再释放贡献。共用工作区同时保留编剧和主持人会话，源剧本删除不删除对话历史。

浏览器使用 PaperMoon UI 和 DSH 主题变量，来源信息放在会话标题栏。轨迹分别展示初始化资料和实际模型请求，只有后者计入模型用量。DSH 补丁提供通用列表与搜索展示，不解释剧本数据。

## 验证

单元测试使用临时 SQLite 文件，在测试仅凭产物初始化前关闭编译服务。pnpm test:writer-sessions 使用真实 DSH 和确定性适配器，检查首轮请求前的开场、真实角色、空内容、工具缺席、刷新、Fork、来源删除及窄屏布局。测试创建并停止自己的临时 Web 服务，不使用用户数据或真实模型。
