# 演绎

[English](README.md) | 中文

本插件从修订版本的完整冻结产物启动主持人对话，使用[修订产物读取器与执行器](../story-compiler/README.zh.md)，并接入[共享剧本工作区](../story-workspaces/README.zh.md)。启动演绎只初始化上下文，不编译，不请求模型回复。
## 启动与继续

总览、修订版本页面和演绎模式共用启动对话框。未指定历史版本时选择编号最大的修订版本，再默认选择其第一个冻结目标。新版本没有产物时禁用启动，不转用旧版本。模型选项与默认值来自 DSH。

初始化格式 2 保存来源身份、名称、说明、附件身份、完整产物和校验和。稳定的会话身份让重试保持幂等，来源删除后也能重试。初始化未完成或损坏时拒绝输入。模式、修订版本和产物一经选定即固定。格式 1 不受支持，不迁移，不重新编译。

预置 assistant 文本显示为开场正文，预置 user 文本显示为背景资料，系统提示词可以检查。名称和生产者标签不进入消息正文。首条真实用户输入才触发模型。DSH 原样记录角色、顺序和内容，不伪造模型尝试或用量。稳定消息身份避免刷新或 Fork 后重复插入开场。

## 函数调用与状态持久化

每个演绎拥有独立的初始状态副本。冻结的函数名、说明与参数 Schema 注册到该 Agent 的作用域，随作用域卸载。原生 DSH 工具展示参数、原始返回值和普通错误。平台不提供默认状态查询工具，不自动附加状态或提示词。编剧通过函数返回值或查询函数提供所需信息。

同一演绎内的调用串行执行。调用身份取自日志中的工具调用序号，同时保留原始调用 ID 和解析后的参数。执行成功后，校验候选状态、返回值和完整记录大小，再追加一条 papermoon.performance.action 配置记录，包含调用、结果、结果状态和前一项校验和。会话持久化确认后才交付结果。同一条调用记录重试时返回原结果；另一条调用可以再次执行。

追加前抛错、取消、超时或校验失败，状态保持不变。提交后的取消不撤销状态。持久化无法确认提交时，该执行实例停止后续调用，并在宿主错误回执之前记录交付失败标记，不声称已回滚，也不重跑函数。重新打开时读取存储中保留下来的完整记录，不重放函数来重建状态。

恢复使用 DSH 的展示替换机制，将中断或取消的工具回执替换为已记录的提交结果。交付失败标记还可识别插件自身的保存错误，无需匹配错误文案。旧回执仍保存在不可变日志中，早期请求仍可重建。其他工具策略拒绝保持原样。恢复本身也需持久化确认。保存尚未确认的活动实例会一直阻止调用，直到重新加载会话运行实例，再读取存储中的记录。

Fork 继承选定日志前缀的状态，之后独立推进。来源删除不影响持有完整产物的会话。来源附件损坏会阻止新演绎启动；会话产物或动作链损坏会阻止继续。两者都不修复或重新编译。

## 接口与检查

/api/papermoon-performances 下的认证路由提供 scripts、models、choices、state 和 start，Performances 提供相同的内部操作。会话配置记录保存初始化、已提交动作和交付失败标记，不自动进入模型历史。模型历史包含预置消息与普通工具回执。

标题栏的来源菜单提供只读的当前状态和动作检查，已提交动作也显示在轨迹中。编译和修订版本预览展示初始状态及生成的函数声明。UI 使用 PaperMoon 组件和 DSH 主题变量；参数与返回值沿用 DSH 工具外观。

状态检查订阅当前会话的动作记录；收到提交记录或重新加载历史时读取最新状态，切换会话和卸载时撤销订阅。

组合不包含编程指导、自动压缩或结果落盘裁剪。其他显式装配的插件仍可通过普通机制贡献已记录内容。关闭时取消并等待函数调用结束，移除工具和提示词贡献。共享剧本工作区同时保留编剧与主持人对话。

## 验证

临时数据库测试覆盖原始返回值、抛错、串行提交、去重、中断回执、保存失败、历史损坏和 Fork 后的独立状态。真实 DSH 集成在启动前关闭编译器，检查原生请求、作用域工具、持久确认和清理。浏览器场景覆盖声明、工具历史、状态检查、刷新、来源删除和窄屏。测试服务使用隔离数据并在结束时关闭，不调用真实模型。

紧凑对话模式下，主持人的叙述保持可见，包括函数调用前的回复。思考与工具详情仍可折叠。这项组合配置不改变普通 DSH 对话的显示方式，也不修改模型请求。

## 世界线

一个 Session 保存一棵不可变的执行树。根节点引用冻结的初始化资料，后续节点各自保存一次接纳的输入、全部模型步骤、工具动作和结束结果。失败、取消及中断的执行也形成节点。世界线视图按创建顺序分页，与当前路径、正在查看的节点分别维护。在此视图中选择节点或历史结果，只改变正在查看的节点。只有“切换到这里”改变运行位置，并准确停在该节点。世界线页面不提供重 roll。当前位置用标签标明，正在查看的节点用高亮区分，主要按钮用于确认切换。后台更新保留正在查看的节点。

“从这里继续”准确选中一个节点，下次发送成为其子节点。重 roll 从原节点的父节点重用输入，生成兄弟节点。编辑已发送的用户消息后，用修改后的输入从其父节点生成新的兄弟节点。原节点及其后续历史保持不变，附件保留。在对话中切换历史结果，会恢复该候选上次选中的后续位置。编辑和重 roll 均保留输入框中尚未发送的内容。复用的用户输入保留日志中的来源，并按用户气泡展示。

操作 ID 对持久意图去重，选择版本拒绝旧窗口操作。发送与切换通过 Agent 维护机制串行接纳。生成期间仍可编辑输入，但不能发送、排队或插话。未结束的执行只显示运行状态，不创建可变的树节点。执行完成后，先恢复工具回执并确认保存，再用同一条记录封存节点和推进当前位置。恢复时将未结束的执行封存为中断节点，不重放函数。已经接纳、尚未进入模型步骤的输入保留为带来源的上下文，界面标明中断，不伪造回复。回执缺失或保存结果不确定时，阻止后续操作。

必读事件 history/selected 携带有版本的 PaperMoon 节点与选择记录。对话、轨迹、提示词重建及动作状态读取当前祖先路径和正在执行的记录。原始日志与用量保留全部执行。没有世界线记录的既有演绎仍可查阅，但不能继续。平台不推测补树，剧本内容、产物及修订版本附件的格式保持不变。

tree 接口按 offset 与 limit 分页读取不可变摘要，每页最多 100 条；node 返回完整节点、兄弟节点摘要、祖先记录和状态。兄弟节点摘要包含当前路径之外的结果。operation 接收 select、candidate、edit 或 reroll，并要求 operationId 和 expectedVersion；edit 还需提供替换文本。state 包含当前路径及操作控件所需的节点。读取不改变选择。这些接口复用现有认证 API。

世界线历史、上下文组装和实际请求分别标识。默认请求使用完整的选中历史。即使后来切换路径，已记录的请求前缀仍能重建原始输入。本轮不提供窗口、摘要或自定义组装。[设计记录](../../.agents/notes/implemented/architecture/2026-09-16-worldlines.zh.md)说明职责及替代方案。
