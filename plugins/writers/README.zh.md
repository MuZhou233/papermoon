# 编剧管理

[English](README.md) | 中文

## 用途

`@papermoon/writers` 维护编剧配置及起始上下文。侧栏设置按钮上方的入口打开管理页，支持新建、搜索、改名、复制、删除和显式保存。切换页面时，提示词修改保留在内存中；有修改时离开会提供保存、放弃和取消选项，刷新前也会提醒。并发修改会拒绝旧序号的保存，并保留本地文本。

页面分为提示词、工具和设置三个 Tab。提示词页负责系统文本和起始序列，对应模型 `messages` 中可配置的部分；工具页负责工具声明，对应请求中独立的 `tools` 字段。本版工具页只读。目录还展示结果声明和执行属性供查阅，这些内容不属于额外提示词消息，也不是原生工具的参数字段。

设置中提供编剧名称、说明、复制和删除。提示词默认以轨迹式表格显示编号、角色和内容摘要，选中条目后查看完整原文。点击编辑后，表单和消息操作替换预览，退出编辑后恢复预览。编辑和保存控件位于当前 Tab 内。切换 Tab 或退出编辑时若有未保存修改，会提供保存、放弃和取消选项。设置字段纵向排列。

刷新页面或切换编剧后，不恢复编辑状态。浏览器无法保存偏好时，导航和服务端保存仍可使用，只是不再记住页面位置。

配置包含稳定 ID、名称、可选说明、system prompt、有序起始消息和 JSON 元数据。系统提示词和每条起始消息均可填写名称。每条消息包含 ID、`user` 或 `assistant` 角色及原始文本。角色选项会说明该内容是给模型的指令，还是作为历史回复提供的文本。消息保留重复角色、空文本和原有换行。界面编辑提示词和说明；元数据通过内部 API 管理，界面保存时保留。

## 上下文与新建模板

`resolveWriterContext` 返回独立的系统文本和有序角色、正文消息。提示词名称用于编辑器和预览，不进入解析结果。它不替换变量，不追加 DSH 指导，也不将序列合成一条 user 消息。页面使用同一函数生成只读预览；这里展示起始上下文，不是实际模型请求记录。

初始化后编剧列表为空。新建模板仅包含提示词 `你是 PaperMoon 的编剧助手。`，起始序列为空。模板没有持久身份，创建的编剧均可编辑、删除。新建和复制会先打开对话框，允许修改名称与说明，确认后才创建记录，取消不会写入。复制保留原编剧的提示词，使用确认后的名称与说明建立独立配置。每位编剧展示同一组[内置工具](../playbook-tools/README.zh.md)。工具选择暂不支持配置。[编剧会话](../writer-sessions/README.zh.md)负责模型对话，使用这些配置的固定副本。

## 接口与持久化

包的主入口导出配置类型和上下文解析，不加载 SQLite。`/repository` 导出 `WriterRepository`；`/plugin` 挂载 `papermoonWriters` 服务及认证管理接口。API 支持 list、get、create、update、copy、delete、context 和 catalog。更新及删除要求已知序号，每次成功更新推进一次序号。更新替换完整配置，省略的可选名称或说明会被移除，身份与创建时间保持不变。读写遇到数据库占用时均返回 `busy`。复制会为编剧和消息分配新 ID。

插件的必填配置 `path` 指定 SQLite 文件。PaperMoon profile 使用产品数据目录内的 `writers.sqlite`。仓库维护单个连接和短写事务，采用 `DELETE` 日志及 `EXTRA` 同步设置。仓库校验独立的应用标识、声明的表结构和已保存的配置。用户配置不进入 Playbook 内容、修订版本历史或 DSH 预设文件。插件卸载时先撤销接口，等待依赖服务清理，再关闭数据库。

## 验证

运行 `pnpm typecheck`、`pnpm exec vitest run plugins/writers/tests`、`pnpm build:plugins` 和 `pnpm check:plugins:dsh`。`pnpm test:editor writers.spec.ts` 使用临时运行数据验证真实管理页面，不调用模型。[设计记录](../../.agents/notes/implemented/architecture/2026-09-12-writer-definitions-and-tools.zh.md) 说明职责划分和作用域选择。
